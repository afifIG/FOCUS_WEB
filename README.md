I just built my first web app, and I started with almost zero coding knowledge. 🚀

I'm a CSE student, and I love Solo Leveling. So I asked myself: what if my daily to-do list worked like the System?

I built "The System: Daily Quests":
⚔️ Add quests with ranks from E to S
📈 Earn XP, level up and raise your hunter rank
💪 Grow your STR, INT and AGI stats
⏳ Focus timer called the Dungeon Gate
👤 Every 3 completed quests triggers an ARISE moment and adds a shadow to your army
🔥 Daily streaks and penalties for missed quests

Built with plain HTML, CSS and JavaScript, and designed with AI as my learning partner.

Try it here:https://focuswime.netlify.app/
